# Imported preview evidence

These sample files were supplied in the user's September 15 archive. They are for local UI/lesson previews through `run_lab.py`, not evidence of successful Ubuntu provisioning. The audit record is a sample record, not a verified event from the current host. The disk image and packet capture are imported fixtures; their end-to-end tool compatibility has not been established by this merge.

The production installer continues to generate its own files under `/cyberlab/static`, including real audit events and a deleted-file image with a recovery self-test. It does not install these preview fixtures.

Text fixture line endings were normalized and SHA256SUMS regenerated during import. Runtime files under `static/` remain excluded from Git.
